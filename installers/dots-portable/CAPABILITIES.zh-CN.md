# 能力矩阵（2.2.0）

| 范围 | 已实现/证据 | 明确限制 |
|---|---|---|
| 有限producer接纳 | 同producer/project/mission/roles内后续调用自动入既有session | 在线native协调者仍必需；不是永久服务或任意目录执行 |
| 原native两轮 | 一次spawn、同worker一次followup；两个gateway consumed，无父级逐轮转发 | 简单默认options文本调用，不是完整Manager或研究五角色 |
| 所有权/恢复 | durable owner、跨session操作和旧host接管拒绝、精确重复receipt幂等 | 同UID恶意进程不受密码学隔离；真实崩溃/取消竞争未在该native试跑验证 |
| Runtime选择 | dots与9个CLI分开，无fallback；角色工厂显式host依赖 | 普通Web/CLI缺host与强制控制时unavailable |
| 缓存与配置 | backend/model/effort变更清旧CLI warm/thread/plan缓存 | 不清除模型/effort来假装兼容 |
| 五角色权限 | 原只读、tools-disabled、隔离等逐调用门禁保留 | 当前native options仍空，不声称完整研究能力 |
| 便携安装 | 64payload/730base，旧版本maps、原件备份及完整元数据检查 | 未知版本/用户后改拒绝；最老实包本轮缺字节，不虚报重跑 |
| UI资料 | TypeScript帮助源码同步 | tracked预编译bundle未重建，不声称UI发行物全部同步 |
| 费用/常驻 | usage缺失保持unknown；有限session不延长 | 无费用控制保证、自动native唤醒或长期daemon |

当前测试数见 `VALIDATION.json`。源集成2805/8skip与补测6项、各focused/独审均有重叠；历史2.1.x全库与native结果继续保留但不作2.2.0全库或生产验收。没有新native试验、服务重启或用户研究提交。
